# Nasha Family Portal

# Проект: Премиум-сайт телекомпании «Наша 7Я — наша семья»

Создай суперсовременный, стильный и эмоциональный корпоративный сайт для семейной телекомпании «Наша 7Я — наша семья». Это телевизионный канал о семье, отношениях, детях и теплых историях. Сайт должен вызывать ощущение уюта, доверия и современности одновременно.

## 🛠 Технологии и стек
- React 18 + Vite
- Tailwind CSS v4 с кастомной дизайн-системой
- Framer Motion для продвинутых анимаций
- Lucide React для иконок
- Radix UI для доступных компонентов
- React Router для навигации
- Shadcn/ui компоненты (кастомизированные)

## 🎨 Дизайн-система

### Цветовая палитра
**Светлая тема (по умолчанию):**
- Основной фон: #FAFAFA (мягкий белый)
- Акцент 1: #FF6B6B (тёплый коралловый — сердце, семья)
- Акцент 2: #4ECDC4 (мятный — свежесть, жизнь)
- Акцент 3: #FFD93D (солнечный жёлтый — радость)
- Текст основной: #1A1A2E
- Текст вторичный: #6B7280

**Тёмная тема:**
- Основной фон: #0F0E17 (глубокий тёмно-синий)
- Акценты сохраняются, но с повышенной насыщенностью
- Текст основной: #FFFFFE
- Текст вторичный: #A7A9BE

### Типографика
- Заголовки: "Unbounded" или "Playfair Display" — современный serif с характером
- Основной текст: "Inter" — чистый sans-serif
- Особый акцентный шрифт для крупных заголовков: огромные размеры (clamp(3rem, 8vw, 8rem))

### Переключатель тем
Сделай красивый переключатель светлой/тёмной темы в шапке (анимированная иконка солнца/луны с морфингом через Framer Motion). Сохраняй выбор в localStorage. Тема должна переключаться с плавным переходом цветов через CSS-переменные.

## 🏗 Структура сайта

### 1. Навигация (Header)
- Плавающая шапка с эффектом размытия (backdrop-blur) при скролле
- Логотип слева: стилизованная цифра «7» с сердечком внутри
- Меню: Главная, О нас, Программы, Ведущие, Эфир, Новости, Контакты
- Кнопка «Смотреть онлайн» с живым индикатором (пульсирующая точка)
- Переключатель темы
- На мобильных — бургер-меню с полноэкранным оверлеем и плавными анимациями появления пунктов

### 2. Hero-секция (Первый экран — ВАУ-эффект)
- Полноэкранный hero с большой фотографией/видео фоном (семья, улыбки, тёплая атмосфера)
- Анимированный текст-заголовок, появляющийся побуквенно с эффектом печатной машинки
- Большой заголовок: «Наша 7Я — это твоя семья» с градиентной подсветкой ключевых слов
- Две CTA-кнопки: «Смотреть эфир» (основная, с микроанимацией пульсации) и «Наши программы» (outline)
- Плавающие декоративные элементы: сердечки, звёздочки, иконки с parallax-эффектом при движении мыши
- Счётчик онлайн-зрителей, обновляющийся в реальном времени

### 3. Секция «О телекомпании» с интерактивным таймлайном
- Крупный заголовок с эффектом reveal при скролле
- Текст о миссии в две колонки с большой эмоциональной фотографией
- Горизонтальный интерактивный таймлайн истории канала (2010 — основание, 2015 — первый эфир, 2020 — миллион зрителей, 2024 — ребрендинг, 2026 — настоящее)
- При наведении на точки таймлайна — анимированные карточки с фактами
- Блок со статистикой: «15 лет в эфире», «2М зрителей», «150+ программ», «50 ведущих» — числа анимируются при появлении (count-up эффект)

### 4. Секция «Программы и шоу» — необычная сетка
- Bento-grid (разноразмерные карточки) как у Apple/Vercel
- Каждая карточка программы:
  - Большое фоновое фото
  - При hover — карточка слегка поднимается, появляется затемнение и краткое описание
  - Плавный zoom изображения
  - Индикатор «В эфире сейчас» для текущей программы
  - Рейтинг и количество выпусков
- Примеры программ: «Семейный ужин», «Утро с 7Я», «Родительский час», «Детский час», «Истории любви», «Бабушкин рецепт»
- Фильтры по категориям: Утренние, Дневные, Вечерние, Детские, Документальные
- Плавное переключение между фильтрами через AnimatePresence

### 5. Секция «Наши ведущие» — карусель с 3D-эффектом
- Заголовок «Лица, которых вы любите»
- Карусель ведущих с tilt-эффектом (наклон карточки в сторону курсора)
- Круглые фотографии ведущих с цветной обводкой
- При hover — разворот карточки с биографией и соцсетями
- Клик — модальное окно с полным профилем, галереей и списком программ

### 6. Секция «Онлайн-вещание» — плеер
- Встроенный видео-плеер (симуляция живого эфира)
- Текущая программа с таймером до окончания
- Программа передач на сегодня (расписание) сбоку
- Возможность выбрать другой канал (если несколько)
- Кнопка «Напомнить о программе»

### 7. Секция «Закулисье» — необычная галерея
- Masonry-layout фотогалерея (разная высота)
- Lightbox с плавным появлением при клике
- Фильтры: Съёмки, Ведущие, За кадром, События
- Lazy loading изображений с skeleton-loader
- Подписи к фото с эффектом появления

### 8. Секция «Истории зрителей» — необычный формат
- Карусель отзывов в формате «историй» (как в Instagram)
- Видео-отзывы и текстовые
- Возможность отправить свою историю (форма с красивой валидацией)
- Анимированные сердечки, появляющиеся при скролле

### 9. Секция «Новости и статьи» — блог
- Три крупные карточки последних новостей
- Grid последних статей
- Категории и теги
- Форма подписки на рассылку с анимированной галочкой после отправки

### 10. Секция «Контакты и карта охвата»
- Интективная карта России с подсветкой регионов вещания (SVG или Mapbox)
- Форма обратной связи (плавающие лейблы input'ов)
- Блок с адресом, телефоном, email с копи-кнопками
- Социальные сети с анимированными иконками
- Карта проезда

### 11. Футер
- Многоколоночный footer
- Быстрые ссылки
- Подписка на newsletter
- Соцсети
- Юридическая информация
- Копирайт с анимированным годом
- Кнопка «Вверх» с плавным скроллом

## ✨ Анимации и микроинтеракции (ОБЯЗАТЕЛЬНО)

1. **Scroll-triggered анимации** через Framer Motion: fade-in, slide-in, scale для всех секций
2. **Cursor follower** — кастомный курсор в виде кружка с эффектом следования (только на десктопе)
3. **Parallax** эффекты на hero и секции «О нас»
4. **Magnetic buttons** — кнопки, которые слегка притягиваются к курсору
5. **Split-text** анимации для крупных заголовков
6. **Marquee** — бегущая строка с хэштегами (#наша7я #моясемья) под hero
7. **Smooth scroll** через Lenis или нативный CSS scroll-behavior
8. **Stagger-эффект** для списков и карточек
9. **Hover effects** на всех интерактивных элементах
10. **Loader** при первом заходе: анимация логотипа с сердечком

## 📱 Адаптивность (Mobile First подход)
- Все сетки должны корректно ломаться на планшетах и телефонах
- Hero-секция на мобильных: вертикальная композиция
- Меню-бургер с полноэкранным оверлеем
- Touch-friendly элементы (минимум 44x44px)
- Отключение сложных анимаций на мобильных для производительности
- Оптимизированные изображения через srcSet и next/image-подобный подход

## 🎯 Особые требования
- Сайт должен загружаться быстрее 2 секунд
- Использовать семантический HTML5 для SEO
- Accessibility: aria-labels, keyboard navigation, focus states
- Все изображения с alt-текстами
- Оптимизация для Core Web Vitals
- Favicon в виде цифры «7» с сердечком
- OpenGraph теги для красивого отображения в соцсетях

## 💫 Общее настроение
Сайт должен сочетать профессионализм крупной телекомпании и тёплую, домашнюю атмосферу. Никакого корпоративного холода — много воздуха, мягких переходов, тёплых цветов и человеческих эмоций. При этом сайт должен выглядеть как продукт топовой студии дизайна 2026 года.

Начни с создания главной страницы с всеми секциями. Используй большие фото из Unsplash (семейные, тёплые, эмоциональные) для первичного наполнения.
